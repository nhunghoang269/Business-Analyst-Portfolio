# Movie Recommender System

## Business Problem

Streaming platforms need personalised and responsible recommendation systems to improve user engagement, support content discovery and encourage long-term retention.

## Objective

Develop and evaluate recommendation approaches to suggest relevant movies to users while considering business priorities such as personalisation, discovery, engagement and ethical recommendation design.

## Tools Used

* Python
* Pandas
* Scikit-learn
* Recommendation Modelling
* Predictive Modelling
* Evaluation Metrics

## Methodology

1. Defined the recommendation challenge from the perspective of a mid-sized UK streaming platform
2. Prepared movie and user preference data for modelling
3. Explored user-item relationships and movie recommendation patterns
4. Built and compared different recommendation approaches
5. Evaluated model performance using suitable evaluation metrics
6. Selected the most appropriate model based on performance, business needs and ethical considerations
7. Translated model results into practical recommendations for platform improvement

## Key Outputs

* Recommendation modelling workflow
* Model comparison and evaluation
* Personalised movie suggestion approach
* Business interpretation of model performance
* Ethical reflection on fairness, transparency and content diversity

## Business Value

The project demonstrates how recommender systems can support personalisation, improve user experience, encourage discovery of diverse content and strengthen platform engagement. It also highlights the importance of balancing technical performance with ethical and strategic business considerations.
