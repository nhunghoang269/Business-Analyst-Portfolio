# Prescriptive Analytics, Logistics Optimisation & Simulation

## Business Problem

Operations and supply chain teams need to make evidence-based decisions that balance cost efficiency, carbon impact, warehouse performance and resource utilisation.

## Objective

Use optimisation and simulation modelling to evaluate sourcing, transportation and warehouse operation scenarios, then recommend rational decisions based on cost, emissions and operational performance.

## Tools Used

* Excel Solver
* Linear Programming
* VBA / Macros
* Simul8
* Simulation Modelling
* Scenario Analysis
* Sensitivity Analysis

## Methodology

1. Defined the supply chain and warehouse decision problems in business terms
2. Built an optimisation model to compare supplier and transportation options
3. Evaluated trade-offs between cost minimisation and carbon emission reduction
4. Used scenario analysis to explore alternative supply chain decisions
5. Designed a simulation model for warehouse unloading operations
6. Compared forklift allocation and prioritisation scenarios using operational KPIs
7. Translated optimisation and simulation results into managerial recommendations

## Key Outputs

* Optimisation model for sourcing and transportation decisions
* Cost and carbon trade-off analysis
* Scenario comparison for warehouse operations
* Simulation results for forklift allocation policies
* Managerial recommendations based on performance measures

## Business Value

The project demonstrates how prescriptive analytics can support better operational decision-making by comparing alternatives before implementation. The analysis helps managers understand trade-offs, improve warehouse efficiency, reduce unnecessary waiting time and balance financial performance with sustainability objectives.
